# Workspace guide

This guide explains how teams organize documents in a workspace.

## Create a workspace

Choose a short workspace name.

Names may contain letters, numbers, and hyphens.

Select the region closest to most collaborators.

## Invite collaborators

Open **Settings** and select **Members**.

Enter one email address per collaborator.

Invitations expire after seven days.

## Organize documents

Create folders for stable subject areas.

Avoid deeply nested folder structures.

Use tags for temporary initiatives.

## Search

Search indexes titles, body text, and tags.

Quoted searches require an exact phrase.

## Archive a workspace

Export important documents before archiving.

Archived workspaces remain readable for thirty days.
