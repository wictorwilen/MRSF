# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.5.1] - 2026-11-03

### Changed
- Accept `@mrsf/cli` 0.8.x alongside existing supported versions; column offsets remain UTF-16 code units.

## [0.5.0] - 2026-08-18

### Changed
- Reanchoring uses the bounded browser-safe Anchor Mesh core from `@mrsf/cli` 0.7.0.
- Widened the `@mrsf/cli` dependency range through `^0.7.0`.

## [0.4.11] - 2026-06-27

### Changed
- Bumped `@mrsf/cli` dependency range to `^0.5.0` for compatibility with the latest core library.
